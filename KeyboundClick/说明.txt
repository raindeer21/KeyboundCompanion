键影随行

插件启动或重载时不弹窗。之后进入魔光键影自动显示，离开自动隐藏。
副本内可用 /ktgclick 打开或关闭窗口；本局手动关闭后不会反复弹出。
- 提交一次：每次点击提交一个敌人词条，优先首领；没有首领 时随机选择敌人。
- 自动间隔提交：默认关闭，开启后按设定间隔提交。
- 手动和自动共用硬性冷却：两次实际提交至少间隔 1 秒，未匹配的提交也计算冷却。
- 冷却期间手动按钮置灰；过早的点击直接忽略，不会排队补发。
- 延迟滑块：1000～10000 毫秒；每轮重新随机，范围为滑块值的 80%～120%，最低截断至 1000 毫秒。
- 例如设为 1000 毫秒时实际随机范围是 1000～1200 毫秒；设为 2000 时是 1600～2400 毫秒。
- 防闲置开关默认开启，仅自动模式、游戏前台且允许输入时运行，约每 20 秒短按功能键和左右方向键。
- 手动按键、输入框已有文字、聊天输入或确认框出现时暂停防闲置；切后台、停止或卸载时释放已按下的键。
- 前台防闲置尚待整局实机验证，不保证后台有效。
- 关闭窗口、离开副本或卸载插件会停止自动模式。
- 禁止打字、没有敌人或输入界面不可用时暂停提交；失败不会立即重试。
- 不自动排队，不自动离开副本。

当前适配：国服客户端与 Dalamud API 15。原生结构参考 AtmoOmen/FFXIVClientStructs.Expansion
提交 22b9e96bca56aab9d18a60956dfb71c14d3c50c2。提交接口特征码已在本机客户端静态核对。
敌人类型来自本机 CollectEntities 映射和 KTGBNpc 表。Boss 基础 ID 19596（类型1）；
魔法罐基础 ID 19592（类型4）属于随机候选；屏障等类型2/3不参与随机攻击。
禁止打字状态 ID 5347 已从本机简体中文 Status 表核对。

构建：需要 .NET 10 SDK，以及与你的游戏对应的 Dalamud 程序集。
dotnet build KeyboundClick.csproj -c Release -p:DalamudLibPath="%APPDATA%\XIVLauncherCN\addon\Hooks\dev"

只需安装 plugin 文件夹下的 DLL 和 JSON；不需要安装 Daily Routines。
原生接口可能随游戏更新变化，更新客户端后应重新核对。
